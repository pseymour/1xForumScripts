# 1xForumScripts
This is a collection of PowerShell scripts to replace Windows 10 and 11 forum batch scripts for troubleshooting.

Currently, these scripts are in the **very** early stages of migration from batch to PowerShell. These are just for review by other forum members. ***In no way*** should these scripts be executed on production machines by production human beings.
